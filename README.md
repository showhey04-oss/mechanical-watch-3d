# Mechanical Watch 3D

Three.jsで構築する、教育用の機械式時計3Dシミュレーションです。

## 現在の基準版

- バージョン：v3.6.4
- 基準形式：ETA 6498-1級の大型手巻きムーブメント
- 公開方式：GitHub Pages
- 現在の重点：輪列・キーレスワーク・脱進機周辺の構造改修

## 実装済み

- 輪列側／文字板側の分離
- 巻上げ、時刻合わせ、秒停止
- 主ゼンマイ残量とパワーリザーブ
- 輪列、軸、かな、穴石、受
- スイスレバー脱進機
- テンプ・ヒゲゼンマイ
- 歩度、姿勢差、ビートエラー
- 動力・振幅・歩度の連成
- 地板、支持柱、受形状
- 部品選択、透過、分解、表裏分離
- モバイル向けUI

## 現在の主要課題

1. 歯車の噛合いをパラメトリックに再構築する
2. 入石・出石周辺の干渉を解消する
3. 状態別に動く部品を整理する
4. 巻真、巻上げピニオン、スライディングピニオンを一体の軸系として再構成する
