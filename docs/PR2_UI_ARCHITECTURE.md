# PR #2 UIアーキテクチャ整理

## 目的

Refactor Aで確立した機構・描画・操作の基準を維持したまま、左側の操作パネルを利用目的別に整理する。一般操作、学習情報、技術設定を3つのタブへ分け、デスクトップとモバイルの長いスクロールを短縮する。

基準コミットは`c11724a199e427c1c756fe834d6e75ffa2c35430`（v3.11.0 / Refactor A.7）である。

## 情報配置

| タブ | 配置内容 |
| --- | --- |
| 操作 | りゅうず、再生、主要視点、機構視点、確認視点、時刻、表裏分離、分解、構造透過率、速度、断面、背景テーマ、機能表示 |
| 学習 | 選択部品情報、ムーブメント構造表示、表示グループ、材質・機能凡例 |
| 技術 | 教育用モデルの注意書き、輪列・軸受検証、調速機パラメータ、動力・歩度連成モデル、履歴グラフ |

初期表示は「操作」とする。既存コントロールのIDとイベント結線は維持し、静的なDOM再配置だけで各タブへ移した。右上の選択部品情報と学習タブの情報は、同じ`partsInfo`データを`setPartInfo()`から同時に反映し、説明文を二重管理しない。

## タブ制御

`js/panel-tabs.js`はタブだけを管理し、時計状態、機構Object3D、カメラ、レンダラーへアクセスしない。

- `tablist`、`tab`、`tabpanel`と対応するARIA属性を設定
- クリック、左右矢印、Home、Endに対応
- 選択タブ以外を`hidden`にしてフォーカス順とレイアウトから除外
- タブ切替時だけARIA属性と`hidden`を更新
- タブごとの本文スクロール位置を保持
- パネルを折りたたみ、再表示しても選択タブとスクロール位置を保持
- `#body`を唯一のスクロールコンテナとして維持
- 390×844と375×667で3タブを均等幅、44px以上のタップ領域、sticky表示とする

タブ切替はanimation loopへ入れず、毎フレームのDOM探索も追加しない。非表示中も既存の履歴Canvasを破棄・再生成しない。

## 変更しない範囲

次の実装は基準コミットから変更していない。

- 主輪列、日の裏輪列、巻上げ輪列、機構グラフ
- 巻上げ、時刻合わせ、秒停止、A.7キーレス絶対配置
- Three.jsモデル、Geometry、Raycaster選択ロジック
- ArcballControls、カメラ平滑化、適応DPR
- ライト、影、材質、構造透過方式
- 既存URLパラメータと診断APIの出力意味
- Issue #2の透明・影課題

Issue #2は変更もクローズもしていない。
