# Issue #2 最終微調整工程への申し送り

## 現在の判断

Issue #2のPhase 2A.2は、D2a／D2c1／D2c2／D2c3の比較、定量診断、Chromium画像確認、回帰、性能測定までを完了した。この時点でライティング候補の追加反復を停止し、完成時計を対象とする最終微調整工程まで保留する。

- D2c1／D2c2：比較履歴として保持する
- D2c3：自動相対ゲートを全120条件で満たした暫定推奨候補として保持する
- D2c3の採用状態：未採用、query限定、既定描画への統合なし
- 通常アクセス：v3.13.0の既定描画を維持する
- PR #5：Open／Draftを維持する
- Issue #2：Openを維持する

D2c3は最終候補または合格結果ではない。最終微調整を再開するときの比較起点であり、現在のコードを既定描画へ取り込む根拠にはしない。

## Phase 2A.2までに確定したこと

- 旧D2のモバイル初期表示と引き表示の暗化は、約106の初期カメラ距離がlegacy fog 68/125へ重なることが主因だった
- D2a／D2bだけをfog 160/260へ退避すると、物理iPhone再起動後の初期黒潰れは解消方向へ改善した
- 物理iPhoneではnearの内部機構と材質差を識別しやすかった
- initial／farでは中間調がまだ低く、広い暗部と明部のコントラストがOLED上で強く見えた
- D2aとD2bの知覚差は小さく、方位追従D2bに明確な利点を確認できなかった
- D2aをworld固定スタジオの基礎候補、D2bを比較履歴とする
- D2c1／D2c2は全条件ゲートを満たさず、D2c3だけがmedian、p25、dark ratio、clipped ratioの全120条件ゲートを満たした
- D2c3のChromium比較では、中間調を持ち上げながら広範な白飛び、金属の平板化、材質差の消失を認めなかった

物理iPhoneのnear／initial／far評価はD2a／D2bまでの観察である。D2c3のSafari／OLED／Display P3採用判定はまだ行っておらず、最終微調整工程へ送る。

## 保留理由

- 現在は外装が未実装で、暗い地板が時計正面の大部分を占めている
- 最終予定のアイボリー／クリーム系文字板とケースを追加すると、正面の明度分布、反射面積、環境光の戻り方が変わる
- 現時点で照明だけを追い込むと、外装実装後に同じ調整をやり直す可能性が高い
- 金属感を優先した現在のコントラストは、スマートフォンの引き表示で暗部を沈めすぎる
- 完成時計と内部機構を同一の実機レビューで確認し、動画制作前に一括調整する方が適切である

## 再開前に完了する項目

1. 作動音の実装
2. ムーブメント／文字板の寸法・比率調整
3. ケース、風防、文字板、インデックス、針、裏蓋、ラグ、ベルトの実装
4. 外装実装後の完成時計をPC／物理iPhoneで初回実画面確認

上記完了後、動画制作と最終統合レビューの前にIssue #2の最終微調整を再開し、調整後の完成時計をPC／物理iPhoneで最終再確認する。

## 再開時の調整項目

### ライティング

- スマートフォンの引き表示で沈むシャドウ／中間調を、ハイライトを増やさず持ち上げる
- key／fill比を縮める
- 黒フラッグの面積、位置、最低反射レベルを再評価する
- PMREM room／floorの最低反射レベルを再評価する
- アイボリー／クリーム文字板を含めた正面視認性を確認する
- 文字板に依存せず内部機構を識別できる明るさを確保する
- 黄銅、鋼、ルビーの材質差と広い柔らかな反射帯を維持する
- 近接時の白飛びと平板化を防ぐ
- 物理iPhoneのSafariタブ起動とホーム画面起動で確認する

### 透明・影レンダリング

- 構造透過時の中央シャドウ境界
- 100%→99%の`transparent`切替不連続
- 55%→54%の`depthWrite`切替不連続
- モバイルとデスクトップの照明、露出、暗部差
- 最終外装を含む4テーマ・全視点比較

### UIの軽微事項

- 物理iPhoneで時刻入力欄右端に残る軽微な表示ずれ

時刻入力の入力、確定、表示時刻と3針への反映は正常であり、この項目は機能不具合ではない。
