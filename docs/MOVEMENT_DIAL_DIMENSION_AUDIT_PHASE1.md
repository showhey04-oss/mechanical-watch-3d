# ムーブメント・文字板 寸法・比率監査 Phase 1

## 1. 結論

基準コミット `7cd1941c3239f7186a6d83695eab8ba347e2afd9` の v3.14.0 を、寸法・座標・形状を変更せず数値化した。ETA 6498-1の公式ムーブメント径36.60 mmを一次アンカーとすると、現行の基準径36.600000 model unitから導く換算係数は `1.000000 mm/model unit` となる。一方、表示機構を含む現行ムーブメントのY包絡は6.645000 model unitで、公式高さ4.50 mmより2.145 mm、47.6667%大きい。これはPhase 2で層構成を精査する候補であり、本PRでは修正していない。

監査の判定は、基準径と3針の1:1拘束を `KEEP`、文字板・針・スモールセコンドを `REVIEW`、厚さ方向を `ADJUST_PHASE2`、公式図面で確認できないりゅうず・外装関係を `UNVERIFIED` とした。

## 2. 基準と計測方法

- 作業開始時main HEAD: `7cd1941c3239f7186a6d83695eab8ba347e2afd9`
- v3.14.0アプリ実装基準コミット: `90e14647190156d040fbd4aee1e74bf38c3442b3`
- 座標規約: front = negative Y、back = positive Y、文字板上方向 = positive Z、3時方向 = positive X
- 基準中心: `[0, 0, 0]`
- 換算基準: `mainPlate` の外周定義半径18.300000、直径36.600000 model unit
- 地板の実Geometry外接Box、受・輪列・文字板側機構のBox3、各Object3Dのworld座標を明示診断呼出し時だけ取得
- りゅうず・巻真を含めないムーブメント包絡と、全モデル包絡を別集計
- screen-space計測は時刻10:10:30、停止、構造透過100%、非分解、表裏分離なし、パネル閉、作動音OFF、navyテーマで固定

`getDimensionDiagnostics()` は `?dimensionAudit=1` または明示API呼出し時だけBox3と投影値を計算する。通常アクセスでは監査用DOM、Object3D、継続処理を追加しない。診断前後の主要Object3D transformは完全一致した。

## 8. screen-space結果

20条件の全数値は [`screen-space-ratios.json`](evidence/movement-dial-dimension-audit/reports/screen-space-ratios.json) に保存した。frontでは、1280×720の全モデル占有率が幅61.8573% / 高さ103.7113%、390×844が幅106.0265% / 高さ46.2926%、393×852が幅106.0207% / 高さ46.2083%、375×667が幅106.7387% / 高さ56.6832%。モバイルfrontで100%を超える幅はりゅうず端を含む全モデルBoxであり、文字板表示部は各89.25%、89.24%、89.84%に収まる。

side、winding、motion-worksは機構確認用の意図的な近接プリセットで、全モデル外接Boxを画面内へ収めるビューではない。したがって占有率が100%を超える値を実寸または外径の代用にせず、視認対象の位置・余白を比較するためだけに使う。

## 9. 技術的判断

### KEEP

- 36.600000 model unitの基準径とその一次アンカー
- 主輪列と日の裏輪列の中心、歯数、モジュール、ピッチ半径、回転比、位相
- 3針と軸／管の1:1拘束、front/back座標規約、A.7絶対配置

### REVIEW

- 文字板径、インデックス円径、3針長、小秒中心・表示円の視覚階層
- 外装統合前の受・橋の外接範囲と支持対象の関係
- モバイルfrontでりゅうずを含む全幅が画面外へ出る現在の構図

### ADJUST_PHASE2候補

- 6.645000 model unitのY包絡を、地板、輪列、日の裏輪列、受、表示部の層ごとに分解し、公式4.50 mmとの対応範囲を定義する
- 全体を一括スケールせず、基準径・軸中心・噛合いを保護した局所的な厚さ調整を優先する

### UNVERIFIED

- ETA公式ページだけでは確定できない文字板、針、小秒、りゅうず、ケース、ベゼル、風防、裏蓋、ラグ、ストラップ寸法
- 製造公差、クリアランス、潤滑、ばね特性、摩擦、個体差

## 13. 既知制約とPhase 2入口

- 現行Y包絡は「公式キャリバー高さ」と同一の測定定義をまだ確定していない。数値差は有力な再検討信号だが、2.145 mmをそのまま削減する指示ではない
- 受・橋の外接径はXZ軸平行Boxの最大辺であり、最小外接円ではない
- screen-space値はカメラ投影値で、実寸の代用ではない
- 390×844のウォールナット採取数ガード、Issue #2、PR #5、D2c3は本監査の対象外
- Phase 2では一次資料または測定定義を追加し、基準径、輪列中心、噛合い、3針拘束を保護したうえで層厚と文字板階層を個別に提案する
