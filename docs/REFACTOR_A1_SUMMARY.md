# Refactor A.1 実装・検証サマリー

## 変更内容

### 構造透過

- 地板・受の本体、上下加工層、段付き座、支持柱、支持脚、石枠、油溜まり、ねじ座周辺を構造透過対象として明示登録した。
- 登録時に対象メッシュの材質を個別複製し、共有材質を使う歯車、ねじ、ルビーへ透過設定が波及しないようにした。
- 低透過時は対象材質の `depthWrite` を無効化し、100%へ戻すと元の `opacity`、`transparent`、`depthWrite` を復元する。

### 操作と選択

- クリックと `touchend` の二重処理を廃止し、Pointer Eventsへ統一した。
- 6 px以内・450 ms以内の単一ポインター操作だけをタップとして扱い、OrbitControlsで移動が発生した操作、複数ポインター、ドラッグ、長押しは選択しない。
- レイヒット後に、オブジェクトと親階層の表示状態、グループ表示、材質不透明度、`pickable`、診断表示を検査する。
- 構造部品が低透過のときは、奥にある非構造部品を優先する。
- 複数材質を持つメッシュもハイライトでき、選択解除時に全材質を確実に復元する。
- 選択中の部品を含むグループを非表示にした場合は、選択情報を即時クリアする。

### 輪列・キーレスワーク・文字板側

- 巻真軸を `z = -4.0`、内端を `x = 3.35`へ移し、中心車・ミニッツホイールの中心を横切らない外周進入経路へ変更した。
- スライディングピニオンを両面ドッグクラッチとし、位置1は固定巻上げ面クラッチ、位置2は時刻合わせ面クラッチへ接続する。
- 時刻合わせ側は傘歯車、短い斜行中間軸、設定中間車18歯を介して設定車1・2、ミニッツホイールへ伝える。
- 巻上げ側は固定面クラッチ、垂直中間軸、上側中間軸を介して丸穴車・角穴車へ伝える教育用経路を表示する。
- 裏側の加工座を外周段差と内側ポケットへ分け、巻真溝、レバー、ヨーク、ジャンパー、支点座を再配置した。

### 中心軸と表示輪列

- 地板中央を実形状の貫通穴へ変更し、中心車から地板両面をまたぐ連続中心軸を追加した。
- 筒かなを中空管とし、中心軸へ摩擦結合する構造を表示した。
- 時針車の中央穴を拡大し、中空時針管が筒かなの外側へ同軸に被さる構成へ変更した。
- 中心車 → 筒かな → ミニッツホイール → ミニッツかな → 時針車の伝達経路を、共通設定と画面表示の両方で追跡できる。

### カメラ

- 全プリセットを `CAMERA_PRESETS`へ集約し、位置、注視点、正規化済み上方向ベクトルを一括適用する。
- 真上視点は厳密な極点を避け、側面・文字板側・厚さ確認間で上方向が不安定にならないようにした。
- 文字板側へ補助光を追加し、再配置したキーレスワークと日の裏輪列を確認しやすくした。

## 自動検証

`node --test tests/*.test.mjs` で12件すべて成功した。

- 全噛合いの中心距離と軸方向レイヤー
- 回転方向、回転比、動作状態、状態別可動部品
- 非表示グループ・診断部品・選択不可部品の除外
- 低透過構造より内部部品を優先する選択順
- ドラッグ、長押し、複数ポインターを除外するタップ判定
- 巻真と日の裏輪列のクリアランス
- スライディングピニオンの位置1／位置2における非対象歯車とのクリアランス
- 中心軸、筒かな、時針車の同軸・包含関係
- 中心軸が地板上下へ連続すること
- 全カメラプリセットの上方向正規化と極点回避

## ブラウザ確認

- デスクトップ表示で初期化・描画エラー、コンソール警告・エラーがないこと
- 構造透過率100%と20%で、内部輪列の見え方と構造材質の復元を確認
- 20%時に地板より奥の中心車を選択できること
- 選択中の輪列グループを非表示にすると選択が解除されること
- 文字板側、側面、厚さ確認の各プリセットで表示が破綻しないこと
- マウスドラッグとトラックパッド相当のスクロール後に部品が誤選択されないこと
- りゅうず位置2で「時刻合わせ＋秒停止」、位置1で「巻上げ」へ戻ること
- 390 × 844 pxで3D表示、上部情報、下部パネルが横方向にはみ出さず利用できること

## 残る制約・妥協点

- 歯形、ドッグクラッチ、傘歯車は教育表示用の近似であり、製造用歯形や全ての面取りを再現していない。
- 巻上げ上側中間軸は動力経路を明示する模式形状であり、実機固有の丸穴車クラッチ歯形とは異なる。
- クリアランス検証は設定値による2D投影包絡とブラウザ表示であり、CADの3Dソリッド干渉解析ではない。
- 390 × 844 pxのブラウザ確認では単一ポインターの操作とスクロール操作を実施した。実機iPhoneの二本指操作は自動ブラウザで直接生成できないため、OrbitControlsの二本指 `DOLLY_PAN` 設定と複数Pointer Events除外の自動テストで補完した。
