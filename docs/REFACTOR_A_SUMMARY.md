# Refactor A 実装・検証サマリー

## 変更内容

- `js/mechanism-config.js` に主輪列、日の裏輪列、巻上げ輪列、キーレスワーク、脱進機支持位置の設定を集約した。
- 各歯車について、ピッチ半径、歯先円、歯底円、歯数、歯厚相当値、中心座標、車／かなの高さ、厚さ、回転方向、回転比を独立管理する。
- 香箱車からガンギかな、筒かなから時針車、設定車列、角穴車から丸穴車の中心距離をピッチ半径和で算出する。
- 車と次段かなが同じ軸方向面へ配置されるよう、噛合い面を `AXIAL_LAYERS` で定義した。
- りゅうず、巻真、巻上げピニオン、スライディングピニオンを同一軸線へ配置し、位置2ではスライディングピニオンを設定車1側へ移動する。
- アンクル受の下側支持脚を、入石・出石の接触範囲から離れた位置へ移動した。
- 起動時に機構設定を検証し、不整合があればThree.jsシーン構築前に明示的なエラーとする。

## 検証内容

- `node --test tests/*.test.mjs`

  - 各噛合い対の軸方向面が一致すること
  - 歯底円、ピッチ円、歯先円の大小関係
  - 主輪列の回転方向と比率
  - 通常、巻上げ、時刻合わせ、秒停止、ゼンマイ停止の状態判定
  - 状態別可動部品の定義
- ブラウザでThree.js初期化エラーとコンソールエラーがないことを確認した。
- 輪列拡大、真上、厚さ確認、文字板側、脱進機の各視点で表示を確認した。
- りゅうず位置2で時刻合わせ表示と秒停止が有効になり、位置1へ戻すと運転が再開することを確認した。

## 残る制約・妥協点

- 歯形は製造用の厳密なサイクロイド歯形ではなく、教育表示用の近似形状である。
- 巻上げピニオンから輪列側の丸穴車までの伝達は教育用に簡略化しており、実機の全ての面取り、クラッチ歯、軸受形状は再現していない。
- 干渉検証は設定値によるクリアランス検査と標準視点での視覚確認であり、CADのソリッド衝突解析ではない。
