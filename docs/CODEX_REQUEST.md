# Codex依頼文｜Mechanical Watch Study Model v3.6.4

添付した `codex_handoff_mechanical_watch_v3_6_4_bundle.zip` を確認し、同梱の `mechanical_watch_v3_6_4_index.html` を基準に改修してください。

## 目的

Three.jsで作成した教育用の機械式時計3Dモデルについて、現在残っている以下の問題を、局所的な座標修正ではなく、輪列・キーレスワーク・状態遷移のコード構造を整理した上で解消してください。

1. 歯車がまだ完全には自然に噛み合って見えない
2. 入石・出石が支持柱や周辺部品と干渉している
3. 一部の歯車・関連部品が動いていない、または動作が分かりにくい
4. 巻真が巻上げピニオン、スライディングピニオン、りゅうずと構造的につながって見えない

## 最優先事項

### 1. 歯車系のパラメトリック化

各歯車・かなについて、少なくとも以下を独立管理してください。

- ピッチ半径
- 歯先半径
- 歯底半径
- 歯数
- 歯厚相当値
- 中心座標
- 車の高さ
- かなの高さ
- 厚さ
- 回転方向
- 回転比

中心距離は、可能な範囲でピッチ半径の和から自動計算してください。

対象は以下です。

- 香箱車 → 中心かな
- 中心車 → 三番かな
- 三番車 → 四番かな
- 四番車 → ガンギかな
- 筒かな → ミニッツホイール
- ミニッツかな → 時針車
- 設定車列
- 巻真、巻上げピニオン、スライディングピニオン

### 2. 厚さ方向の層構成

車とかなが交互の高さで噛み合うよう、輪列の軸方向レイヤーを定数または設定オブジェクトとして整理してください。

大径車どうしが同一平面で重なって見えないようにしてください。

### 3. 脱進機周辺の干渉解消

入石・出石、フォーク、ロック面、衝撃面の周囲から、支持柱・ねじ・受形状を適切に逃がしてください。

見た目だけではなく、機能上自然な位置関係にしてください。

### 4. 状態別の動作整理

以下の状態ごとに、動く部品を明確に整理してください。

- 通常運転
- 巻上げ
- 時刻合わせ
- 秒停止
- ゼンマイ停止

少なくとも以下の部品が、状態に応じて正しく動くことを確認してください。

- 香箱車
- 中心車
- 三番車
- 四番車
- ガンギ車
- 丸穴車
- 角穴車
- 筒かな
- ミニッツホイール
- 時針車
- 設定車1・2
- 巻上げピニオン
- スライディングピニオン
- 巻真
- りゅうず

### 5. 巻真系の一体化

りゅうずから巻真、巻上げピニオン、スライディングピニオンまでを、一本の軸系として自然につながる構造へ修正してください。

位置1と位置2の切替でも破綻しないようにしてください。

## 維持してほしい機能

以下は現在の仕様を基本的に維持してください。

- 折りたたみ式操作パネル
- 現在時刻・手動時刻・継続同期
- りゅうず位置切替
- 巻上げと時刻合わせ
- 秒停止
- 部品選択と強調表示
- 透過、分解、表裏分離
- 背景テーマ
- 動力・歩度連成
- 履歴グラフ
- スマートフォン対応

高速で位相名が切り替わる「スイスレバー脱進機解析UI」は復活させないでください。

## 完了条件

- 主要歯車が自然に噛み合って見える
- 歯車同士の不自然な重なりや浮きがない
- 入石・出石周辺の干渉がない
- 状態ごとに必要な部品が動く
- 巻真系が構造的につながって見える
- 既存UIと主要機能が壊れていない
- Three.js初期化エラーがない
- 循環参照エラーを発生させない
