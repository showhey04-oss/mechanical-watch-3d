# Refactor A.2 実装・検証サマリー

## 方針

文字板側は方針Bを採用し、機能していなかった設定レバー、ヨーク、ヨークばね、ジャンパー、秒停止レバーの模式形状を標準モデルから削除した。A.1で追加した斜行中間軸、設定中間傘歯車、巻上げ垂直中間軸、巻上げ上側中間軸も削除し、部品を追加せずに次の最小経路へ再構成した。

```text
crown input → stem → sliding clutch → setting input
→ setting transfer → setting wheel 1 → setting wheel 2
→ minute wheel → cannon pinion → hour wheel
```

## 実装内容

### 単一のキネマティックチェーン

- 各ノードに回転軸、初期位相、対応するThree.js `Object3D`を割り当てた。
- 各接続に入力、出力、歯数または伝達比、方向、有効状態を定義した。
- `applyKinematicState()`だけが位置2の全対象オブジェクトへ回転を反映する。
- 位置1では設定入力、設定中間車、設定車1・2をりゅうず入力から切り離す。
- 位置2のりゅうず入力に対する回転比は、設定中間車 `1`、設定車1 `-18/32`、設定車2 `18/32`、ミニッツホイール `-1/2`、筒かな `3/2`、時針車 `1/8`とした。
- 筒かなを基準に、ミニッツホイールは `-1/3`、時針車は `1/12`で動くため、表示輪列の比率を通常運転と時刻合わせで共通化した。

### 歯の初期位相

- 設定中間車―設定車1、設定車1―設定車2、設定車2―ミニッツホイール、ミニッツホイール―筒かな、ミニッツかな―時針車の5組へ `phaseOffset`を導入した。
- 中心線角度、入力歯数、出力歯数から歯先対歯溝となる出力位相を一元計算する。
- 静的検証では5組すべての位相残差が許容値内になった。

### 最小キーレスワーク

- `axialGear()`を廃止し、小径の巻上げ固定クラッチ、二位置移動クラッチ、設定入力クラッチへ置換した。
- 位置1では移動クラッチ右面と巻上げ固定クラッチ、位置2では移動クラッチ左面と設定入力クラッチが接する寸法にした。
- 標準表示に残る文字板側の支持部は設定中間車、設定車1、設定車2の支点座だけとした。
- 巻上げ側は、詳細な模式中間軸を再現せず、既存の丸穴車・角穴車を教育用に分離表示する。

### 3D干渉診断

- 実際の `Object3D`を参照する14個の円柱包絡を定義し、毎回ワールド座標へ変換してX・Y・Z方向の重なりを検査する。
- 意図した接触・包含ペアと禁止干渉ペアを設定から明示した。
- `window.watchModelDiagnostics.getInterferenceReport()`から現在位置の包絡中心、広がり、許可関係、禁止干渉を取得できる。
- 詳細結果は [REFACTOR_A2_INTERFERENCE_REPORT.md](REFACTOR_A2_INTERFERENCE_REPORT.md) に記録した。

### 選択と操作

- 選択可能メッシュだけをRaycaster専用Layer 1へ登録し、非表示、低透過、診断、選択不可の状態変化に合わせて所属を更新する。
- 候補は `pickPriority`、距離、材質不透明度、画面投影面積の順で並べる。
- 歯車・軸・石を優先度3、ねじ・座・支持部を2、地板・受を1、診断を0とした。
- タップ閾値を3.5 px、OrbitControls終了後の抑止を125 ms、重複処理のデバウンスを180 msとした。
- Pointer Captureを使用し、`pointerleave`、`lostpointercapture`、`pointercancel`でジェスチャーを破棄する。

### ブラウザ診断API

`window.watchModelDiagnostics`へ以下を追加した。

- 実Object3Dの現在回転角
- 現在の設定入力角
- 現在状態と接続中の運動経路
- 選択中部品
- カメラ操作中フラグ
- 3D干渉レポート
- Raycaster Layerレポート
- ブラウザ試験用の位置、入力、透過率、フレーム待機操作

## 検証結果

### Node.js設定テスト

`node --test tests/*.test.mjs` を実行し、14件すべて成功した。

- 中心距離、噛合い高さ、歯車半径
- 位置1／位置2クラッチ接触と非対象歯車クリアランス
- 10ノード・9接続の運動連鎖と正逆転
- 5組の歯先対歯溝位相
- Raycaster優先順位とPointer Events判定
- 中心軸、筒かな、時針車の同軸・高さ関係

### 実ブラウザ統合テスト

ローカル配信したThree.jsページを実ブラウザで `?browserTest=1` として実行し、`tests/browser-integration.test.js` の11検査がすべて成功した。

- 位置1で設定入力・設定中間車・設定車1・2がりゅうず入力に連動しない
- 位置2で正転すると、りゅうず、巻真、移動クラッチ、設定入力、設定中間車、設定車1・2、ミニッツホイール、筒かな、時針車の実Object3Dがすべて回転する
- 実測回転比が定義値と一致する（最大誤差は浮動小数点誤差範囲）
- 逆転時に全経路の回転符号が反転する
- 位置1・位置2とも禁止干渉0件
- 14個の実Object3D包絡がワールド座標で取得できる
- 透過率12～16%の地板越しにRaycasterで「設定車2」を選択できる
- 診断部品が選択Layerへ入らない

## 残る制約

- 歯形、小径面クラッチ、クラウン入力は教育表示用の近似であり、製造用インボリュート歯形や実機固有のクラッチ歯形ではない。
- 方針Bを採用したため、設定レバー・ヨーク・ジャンパーの拘束運動はモデル化していない。位置切替はUI状態から移動クラッチ位置を補間する。
- 巻上げ固定クラッチから丸穴車までの詳細な実機伝達は、干渉する模式軸を削除したうえで教育用に分離している。
- 3D干渉検査は実Object3Dへ追従する保守的な円柱包絡であり、CADソリッドの接触解析ではない。
- デスクトップ実ブラウザとレスポンシブUIの既存390 × 844検証を利用した。実機iPhoneの複数指操作は今回の自動ブラウザからは再実施していない。
