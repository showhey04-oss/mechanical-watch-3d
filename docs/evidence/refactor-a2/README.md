# Refactor A.2 browser evidence

The PNG files in this directory were captured from the in-app browser against the local Three.js application. They cover the dial-side overview, cannon/minute works, both crown positions, side height, transparent-part selection, and setting rotation before/after.

The machine-readable browser result is recorded in `docs/REFACTOR_A2_SUMMARY.md` and is produced by `tests/browser-integration.test.js` when the page is opened with `?browserTest=1`.
