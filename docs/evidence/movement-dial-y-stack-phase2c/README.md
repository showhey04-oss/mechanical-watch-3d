この証跡は`tests/y-stack-audit-harness.html`の同一origin iframeから実行時APIを取得したものです。親ページ・iframeとも`http://127.0.0.1:8000`、iframeはsandboxなし、`document.readyState`は`complete`で確認しました。

- `reports/`: 実測値をハーネス出力から保存したJSON
- `desktop-side.png` / `mobile-390-side.png`: 固定viewportのside監査表示
- その他のPNG: 基準面、レイヤー、3包絡の確認用画像
- `evidence-manifest.json`: 閉世界SHA-256 manifest
