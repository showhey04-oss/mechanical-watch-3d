# Phase 3B.1 E-BALANCEDコア外装候補 実装報告

## 結論

Phase 3Aで`APPROVED_FOR_PHASE_3B_IMPLEMENTATION`とされたE-BALANCEDを、`?exterior=balanced`の明示query時だけ生成するThree.js Geometryとして実装した。状態は`IMPLEMENTATION_CANDIDATE_NOT_DEFAULT`であり、通常表示への既定採用は行っていない。

第1候補の人間確認では、りゅうず位置1の食い込み、指掛かり、pull／push、位置2、カメラ、外装選択、透過100%／16%、時計機能、作動音、PC／物理iPhone性能が合格した。第2候補ではケース胴シルエット、前後テーパー、正面／裏面比率、ベゼル、外装総厚、ムーブメント保持リングを改めて確認する。透過50%は判断保留である。人間確認前に`ADOPTED`または最終外装完成とはしない。

## 接触と干渉

意図接触：

- ケース胴 ↔ ベゼル
- ベゼル ↔ 風防保持候補
- ケース胴 ↔ 裏蓋リング
- ケース胴 ↔ ケースチューブ
- ケース胴 ↔ ムーブメント保持リング
- 文字板blank ↔ 文字板支持候補
- ケースチューブ ↔ 位置1りゅうず局所シート候補

禁止干渉14組を個別記録し、位置1／位置2とも0件だった。主な正の余裕は、風防―分針0.350、文字板―3針0.180、文字板穴―軸／管0.100以上、裏蓋―ブリッジ0.400、ケース―ムーブメント0.600、保持リング―ケース0.075、保持リング―ムーブメント0.075、チューブ内径―巻真0.100である。チューブ軸誤差は0である。

りゅうず―ケース胴は禁止干渉である。一方、りゅうず―ケースチューブとりゅうず―局所接続カラーは、意図接触または未検証シートへ分類し、禁止干渉件数へ混在させない。承認寸法では位置1のりゅうず内面がチューブ外端へ0.056857入る。この局所関係は`PHASE3B1_IMPLEMENTATION_ASSUMPTION`としてraw gapを隠さず保存した。位置2では軸方向gap 1.293143を持つ。指掛かりとpull／push操作感は第1候補の人間確認合格を継承する。シート形状、ガスケット、ねじ、圧入、防水、製造公差、保持リング固定方式は`UNVERIFIED`である。

## Materialと透過

既存Materialを変更せず、外装専用cloneまたは外装専用`MeshStandardMaterial`を使用した。ケース、ベゼル、rehaut、文字板、裏蓋リング、ムーブメント保持リング、チューブ、接続カラーは既存の構造透過スライダーへ登録し、風防と裏蓋窓は固定透明材とした。

light、shadow、tone mapping、exposure、fog、DPR、既存透過方式は変更していない。D2c3とalphaHashは使用していない。100%／50%／16%の実WebGL画像を保存した。100%／99%、55%／54%の既知課題は本PRで修正せずIssue #2へ維持する。

## 選択

外装10部品を既存register経路へ登録した。保持リングはpick priority -1とし、内部部品選択を常に奪わない。第1候補の実pointer確認でケース胴の強調、右上HUD、説明、学習タブ同期、背景解除、透過16%の内部`設定車2`選択が合格しており、HUD回帰57/57を維持した。

文字板、風防、裏蓋窓のpick priorityを0として、外装が常に内部選択を奪わないようにした。Raycaster、既存opacity閾値、UIは変更していない。
