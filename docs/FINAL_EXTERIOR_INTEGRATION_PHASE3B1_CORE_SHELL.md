# Phase 3B.1 E-BALANCEDコア外装候補 実装報告

## 結論

Phase 3Aで`APPROVED_FOR_PHASE_3B_IMPLEMENTATION`とされたE-BALANCEDを、`?exterior=balanced`の明示query時だけ生成するThree.js Geometryとして実装した。状態は`IMPLEMENTATION_CANDIDATE_NOT_DEFAULT`であり、通常表示への既定採用は行っていない。

実装・自動回帰は合格した。次の判断はPCと物理iPhoneによる外装比率、表示開口、指掛かり、pull／push操作性の人間確認である。人間確認前に`ADOPTED`または最終外装完成とはしない。

## 接触と干渉

意図接触：

- ケース胴 ↔ ベゼル
- ベゼル ↔ 風防保持候補
- ケース胴 ↔ 裏蓋リング
- ケース胴 ↔ ケースチューブ
- 文字板blank ↔ 文字板支持候補
- ケースチューブ ↔ 位置1りゅうず局所シート候補

禁止干渉は既存10組と「りゅうずコア／外周歯―ケース胴」を分離して個別記録し、位置1／位置2とも0件だった。主な正の余裕は、風防―分針0.550、文字板―3針0.180、文字板穴―軸／管0.100以上、裏蓋―ブリッジ0.650、ケース―ムーブメント0.600、チューブ内径―巻真0.100である。チューブ軸誤差は0である。

りゅうず―ケース胴は禁止干渉である。一方、りゅうず―ケースチューブとりゅうず―局所接続カラーは、意図接触または未検証シートへ分類し、禁止干渉件数へ混在させない。承認寸法では位置1のりゅうず内面がチューブ外端へ0.056857入る。この局所関係は`PHASE3B1_IMPLEMENTATION_ASSUMPTION`としてraw gapを隠さず保存した。位置2では軸方向gap 1.293143を持つ。指掛かり、pull／push操作感、シート形状、ガスケット、ねじ、圧入、防水、製造公差はすべて`UNVERIFIED`であり、合格扱いにしない。

## Materialと透過

既存Materialを変更せず、外装専用cloneまたは外装専用`MeshStandardMaterial`を使用した。ケース、ベゼル、rehaut、文字板、裏蓋リング、チューブ、接続カラーは既存の構造透過スライダーへ登録し、風防と裏蓋窓は固定透明材とした。

light、shadow、tone mapping、exposure、fog、DPR、既存透過方式は変更していない。D2c3とalphaHashは使用していない。100%／50%／16%の実WebGL画像を保存した。100%／99%、55%／54%の既知課題は本PRで修正せずIssue #2へ維持する。

## 選択

外装9部品を既存register経路へ登録した。実pointerおよび既存選択queryでケース胴を選択し、強調、右上HUD、説明、学習タブ名が一致した。背景解除経路で名称が「なし」へ戻りHUDが消えることはHUD回帰57/57で維持した。構造透過16%では既存診断queryにより内部の`設定車2`を選択し、HUDと学習タブ同期を確認した。

文字板、風防、裏蓋窓のpick priorityを0として、外装が常に内部選択を奪わないようにした。Raycaster、既存opacity閾値、UIは変更していない。
