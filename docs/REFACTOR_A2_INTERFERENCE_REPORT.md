# Refactor A.2 3D干渉検査結果

## 検査方式

`index.html`の実際のThree.js `Object3D`へ円柱包絡を関連付け、各フレームのワールド変換後に干渉を判定した。平行軸同士は軸方向区間と半径方向距離、直交軸同士は円柱から導いたワールドAABBのX・Y・Z重なりを使用する。判定許容値は0.015モデル単位である。

対象包絡は次の14個。

1. 巻真
2. 巻上げ固定クラッチ
3. 二位置移動クラッチ
4. 設定入力クラッチ
5. 設定中間車
6. 設定車1
7. 設定車2
8. ミニッツホイール
9. ミニッツかな
10. 筒かな12枚
11. 筒かな管
12. 時針車
13. 時針管
14. 中心軸

## 結果

| 状態 | 禁止干渉数 | 結果 |
|---|---:|---|
| 通常表示・位置1 | 0 | 合格 |
| 位置1・正転入力 | 0 | 合格 |
| 位置2・停止 | 0 | 合格 |
| 位置2・正転／逆転後 | 0 | 合格 |

実ブラウザ統合テストが位置1と位置2で `getInterferenceReport()`を呼び出し、禁止ペア配列が空であることを検証した。回転部品は軸対称包絡のため、正転・逆転後も同じ禁止干渉結果になる。

## 状態別の許可関係

- 位置1では二位置移動クラッチと巻上げ固定クラッチが接し、設定入力クラッチとの間には2.4モデル単位の軸方向離隔がある。
- 位置2では二位置移動クラッチと設定入力クラッチが許容値内で接し、巻上げ固定クラッチとの間には約2.4モデル単位の離隔がある。
- 設定入力と設定中間車、設定中間車と設定車1、設定車1と設定車2、設定車2とミニッツホイール、ミニッツホイールと筒かな、ミニッツかなと時針車は許可した噛合い関係として検出される。
- 中心軸―筒かな管、筒かな管―時針管は同軸包含として許可リストへ登録している。後者は軸方向に0.04モデル単位の設計離隔があり、物理的な貫通としては検出されない。

## 禁止ペア

巻真・各クラッチと非対象設定車、非隣接の設定車同士、設定車と筒かな／時針車、ミニッツホイールと高さを分けた時針車、ミニッツかなと筒かな管を禁止ペアとして明示した。位置1・位置2とも検出件数は0だった。

## 制約

この診断は画面内の実Object3D配置・移動へ追従するが、歯面の局所接触や面取りを解析するCADソリッド干渉ではない。円柱包絡は明らかな貫通を早期検出するための保守的な近似である。
